# GUI

This project implements a simple graphical user interface from scratch using the C language. With it, you can draw basic shapes like lines rectangles, and also display bitmap images. It is meant to run on a DOS machine so you might want to install a DOS emulator like dosbox.

## Features

- Draw coordinates
- Lines
- Draw rectangles
- Draw bitmap images

### Tech Stack

- **C**
- **Assembly**

## Installation
You will need to clone this repository first. Change into the gui directory of the project and run the make utility using the ```make``` command. Open dosbox and mount your present working directory, like so ```mount c /your/present/working/directory```. Change directory to the C drive using ```c:```. Now run ```gui``` and there you go!

```bash
git clone https://github.com/BenedictKariuki/GUI.git
cd gui
make
```

To install dosbox on Linux, run
```bash
sudo apt install dosbox
```
